# NetBird for Synology 0.81.2-2

Community-maintained fork of TechHutTV/netbird-dsm, packaging base 5efc24c. Includes official NetBird client 0.81.2. This is an unofficial community package, independent of NetBird and Synology.

## Changes
- Six interface languages: English, Simplified Chinese, Traditional Chinese, German, French and Japanese.
- System, light and dark appearance; language and appearance controls aligned with the logo.
- Online release discovery every 24 hours while the app is open; the last check and release result persist in the browser. Manual checks remain available.
- Release version, publication date, package size, plaintext release notes and architecture-specific SPK download.
- Official core archive checksum verification; core copyright/license included.
- Update installation is handled by DSM Package Center. In-app one-click installation is not included.

## Downloads and updates
Choose amd64 for supported Intel/AMD NAS models or arm64 for supported 64-bit ARM models. DSM 7.0 or later is required. Add the architecture-specific package source documented in README for Package Center updates.

132 Linux Python tests passed before the presentation refinements; the later status/authentication regression and 11 frontend tests passed. CI runs the complete suite for this release. NAS install/upgrade/reboot and live VPN acceptance remain pending. Use independent LAN access during upgrade; VPN briefly disconnects. Translation drafts still need native-speaker review.
